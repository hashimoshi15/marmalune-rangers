# Marmalune Rangers

ブラウザで遊べる3Dアクションゲーム（スマホ横画面・PC対応）。
A 3D action game you can play in the browser (phones in landscape, and desktop).

**▶ Play: https://hashimoshi15.github.io/marmalune-rangers/**

- 宇宙レース、探索ミッション、ナワバリバトル、バトルロイヤル、拠点防衛、トレーニング
- 部品集め・クラフト・ギルドクエスト・改造ルーム
- 12言語対応 / 12 languages
- セーブデータは各端末のブラウザ内に保存されます / Progress is saved in each device's browser.

現在の版 / Current version: **v1.1.0**（タイトル画面右上に版とビルドIDを表示 / shown top-right on the title screen）

`index.html` is a single self-contained build (three.js is loaded from jsDelivr).
Source & changelog: private development repository (game/CHANGELOG.md).
